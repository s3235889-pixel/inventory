# 標籤工房｜商品保存期限貼紙編輯器

繁體中文標籤編輯器，可在 Windows 的 Chrome 或 Edge 使用。預設貼紙尺寸為 **35 × 25 mm**，可自行修改。

## 開始使用

1. 下載此儲存庫（Code → Download ZIP）並解壓縮。
2. 進入 `label-workshop` 資料夾，用 Chrome 或 Edge 開啟其中的 `dist/Label-Workshop.html`。
3. 填寫商品名稱、標題、保存方式與製造日期，再設定保存天數或指定有效日期。
4. 在畫布拖曳文字，或用右側設定調整字體、字級、座標、寬度與旋轉。
5. 按「列印貼紙」確認預覽。若瀏覽器沒有開啟列印視窗，可按「輸出 PDF」。

程式為單一 HTML 檔案，已包含全部 HTML、CSS 與 JavaScript，不需要安裝套件、伺服器或 API 金鑰。

## 功能

- 貼紙寬、高設定，預設 35 × 25 mm。
- 新增、拖曳、複製及刪除文字與分隔線。
- 字型、字級、粗體、對齊與旋轉設定。
- 商品欄位自動帶入標籤，以及保存期限日期計算。
- 即時預覽、格線、吸附、縮放、復原與重做。
- 本機自動儲存、常用版型及 JSON 匯出／匯入。
- 列印張數、單張試印及水平／垂直位置校正。
- 列印無回應提示與原尺寸 PDF 輸出。
- 行動版彈出視窗固定操作列，內容可獨立捲動。

## 列印設定

- 選擇已安裝的貼紙機，驅動程式紙張尺寸設為與程式相同。
- 縮放設為 **100%／實際大小**，邊界設為「無」，關閉頁首及頁尾。
- 系統列印視窗的份數設為 **1**；程式會依指定張數產生對應頁數。
- 手機或 App 內建瀏覽器可能不支援直接列印，請輸出 PDF 後使用系統檢視器列印。
- 若貼紙機只連接 Windows，請在該電腦列印 PDF。
- 第一次請先試印一張，確認尺寸及位置後再大量列印。

PDF 每頁使用設定的毫米尺寸，影像最高為 600 dpi（最長邊上限 4096 像素）。

## 資料保存

商品與版型保存在目前瀏覽器的 localStorage。不同瀏覽器、裝置或檔案網址不共用資料；更換環境前請匯出 JSON 備份。清除瀏覽器資料可能移除儲存內容。

## 檔案

| 路徑 | 用途 |
| --- | --- |
| `dist/index.html` | 網站入口與完整程式碼 |
| `dist/Label-Workshop.html` | 可直接開啟的離線單檔版 |
| `dist/Label-Workshop-source.txt` | 便於查看與複製的完整原始碼 |
| `qa/check.cjs` | 日期、匯入驗證、離線版本一致性與列印樣式檢查 |

三份程式檔內容相同，修改後請一併同步。

## 開發與檢查

不需要編譯。若要執行檢查，安裝 Node.js 後在儲存庫根目錄執行：

```sh
cd label-workshop
node qa/check.cjs
```

已檢查 1 頁與 3 頁 PDF 的頁數及 35 × 25 mm 尺寸，並檢視中文字輸出。實際 Windows 驅動、iOS 分享列印與貼紙機出紙仍需在使用者的設備上試印。
